# DailyInterviewPrep

My interview-prep working repo: coding problems, system design exercises, behavioral stories, and mock-interview debriefs.

## Layout

| Folder | What's in it |
|---|---|
| `coding/` | Coding problem reps, organized by pattern |
| `system-design/` | System design exercises and architecture study guides |
| `behavioral/` | STAR story bank for leadership / behavioral rounds |
| `mock-interviews/` | Debriefs from practice interview sessions |
| `logs/` | One file per day: reps completed, topics studied, notes |

## Daily routine

- 5 coding problems
- 1 system design exercise
- 1 behavioral story
- Log it all in `logs/YYYY-MM-DD.md`
