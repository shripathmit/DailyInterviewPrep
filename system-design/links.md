# System Design — Study Links

- [ByteByteGo](https://bytebytego.com/) — Alex Xu's system design newsletter and diagrams.
- [Grokking the System Design Interview](https://www.educative.io/courses/grokking-the-system-design-interview) — structured course on common design problems.
