# Coding

Solutions organized by pattern. One file per problem, named `<slug>.md`:

- Problem statement (link to source)
- Approach in plain words
- Code
- Time / space complexity
- Edge cases that matter

## Pattern taxonomy

Create a subfolder per pattern as solutions land:

- arrays-and-strings
- two-pointers
- sliding-window
- binary-search
- linked-lists
- trees-and-graphs
- heaps-and-priority-queues
- dynamic-programming
- intervals
- system-design-flavored coding (LRU cache, rate limiter, etc.)
